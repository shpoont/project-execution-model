# Working Materials

The editable [overview diagram](diagrams/project-execution-model-overview.html)
is kept here. Its PNG output is in
[deliverables/assets](../deliverables/assets/project-execution-model-overview.png).
When changing it, review the source and resulting image together and keep the
model's explanation and alternative text consistent with the result.

For a PNG export, render the HTML in a browser with a 1280 × 864 CSS-pixel
viewport at 2× pixel density, wait for fonts to load, and capture the complete
SVG. This produces the existing 2560 × 1728 image size. Compare labels, fonts,
line breaks and cropping with the current PNG before replacing it; a browser
or font change can alter the rendering.

The [model Markdown](../deliverables/project-execution-model.md) is both source
and delivered text. Edit that one file; do not create a second model under `src/`.
The café illustrations are maintained as PNG assets; no separate editable café
artwork is held in this repository.

Proposed passages, sketches and comparisons belong with the relevant issue or
proposal branch. Keep their purpose, findings and remaining uncertainty connected
to that work through the [repository guide](../docs/README.md).
